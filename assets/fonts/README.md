# テロップ用ローカルフォント

`remotion/public/fonts/` と `desktop/public/fonts/` に同一ファイルを配置して使う。
（正本はこのディレクトリ。追加・更新時は両方へコピーすること）

| ファイル | フォント名 | 用途 | ライセンス | 入手元 |
|---|---|---|---|---|
| GenEiGothicN-U-KL.otf | 源暎ゴシックN U-KL | テロップ既定(超極太・仮名拡大) | SIL OFL 1.1 | https://okoneya.jp/font/ |
| GenEiGothicN-H-KL.otf | 源暎ゴシックN H-KL | テロップ(Heavy) | SIL OFL 1.1 | https://okoneya.jp/font/ |
| GenEiKiwamiGo.ttf | 源暎きわみゴ | テロップ特化ゴシック | SIL OFL 1.1 | https://okoneya.jp/font/ |
| GenEiPOPle-Bk.ttf | 源暎ぽっぷる Black | ポップ体 | SIL OFL 1.1 | https://okoneya.jp/font/ |
| keifont.ttf | けいふぉんと | カジュアル・相槌 | Apache License 2.0 | http://font.sumomo.ne.jp/font_1.html |
| LanobePOP.otf | ラノベPOP | 煽り・タイトル | M+ FONTSライセンス(商用・埋め込み可) | https://www.fontna.com/blog/lightnovel.html |

- いずれも商用利用・動画への使用・プログラム埋め込みが許可されている。
- ラノベPOPは新版(V2)が BOOTH(要pixivログイン)で配布されている。ここに置いてあるのは直リンクで取得できる旧版。
- CSS/Remotion に登録している family 名: `GenEi Gothic N U-KL` / `GenEi Gothic N H-KL` / `GenEi Kiwami Go` / `GenEi POPle Bk` / `Keifont` / `LanobePOP`
