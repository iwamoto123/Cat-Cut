## 0. この動画のジャンルと編集方針（ひとことで）

BtoB向けビジネス系YouTube。**グレーのソファに男性2人が並んで座る固定2ショット**を基本画面に、**全編びっしり入るテロップ（話し言葉をほぼ全文字幕化）**＋**実績を裏取りするB-roll挿入（スクショ・グラフ・サムネ）**で構成。テロップは「黄色ベタ袋文字」を主役に、感情・数字・質問で配色を切り替える“うるさすぎない情報番組”系の作り。

## 5. 他AIへの再現指示テンプレ（コピペ用）

> 以下を「切り抜きショート／同テイスト横型動画」を作る別AIにそのまま渡せる。

```
【動画テイスト指定】
・ジャンル: BtoB経営者の対談トーク（グレーソファ2ショット固定）
・テロップ方針: 話し言葉をほぼ全文字幕化。2〜4秒ごとに1〜2行で切り替え。全て太ゴシック袋文字（縁取り）。

【下部メインテロップの配色ルール】
- 事実・説明・本筋           → 黄色ベタ＋黒フチ（デフォルト）
- ニュートラルな相槌・引用「」 → 白ベタ＋黒フチ＋薄い青の第2縁
- 感情・驚き・断言・煽り       → 赤/マゼンタベタ＋白文字＋白フチ
- 聞き手の質問・ツッコミ       → 青ベタ＋白文字
- 軽い返し・相槌             → 水色ベタ＋黒フチ
- 特別に強い煽り/ネガ         → 紫グラデ＋白フチ（装飾袋文字）
- 文中の数字・金額・固有名詞    → その語だけ赤/ピンク文字にハイライト
- 話のオチ・要約・言い切り      → 黄色い長方形ボックス＋黒文字（2行）

【固定要素】
- 左上に章見出し（白フチ黒文字）を常時表示。章が変わるまで固定。
- 冒頭のみ毛筆風/手書き風フォントの煽りテロップ＋赤2行フック＋人物紹介ボックス（氏名+肩書+ロゴ）。
- CTAは黄色ベタで「概要欄の公式LINEに『◯◯希望』」を後半で繰り返す。

【B-roll（実績の裏取り）の型】
実績・数字・固有名詞が出るたびに:
  背景を強くぼかす → 中央に証拠画像を赤枠で配置 → 下部に白フチ黒字キャプション
  素材: YouTubeアナリティクスの折れ線グラフ / X投稿・プロフィールSS / YouTubeチャンネル・設定画面SS / 過去動画サムネ / 企業ロゴカード / 自社ショートのサムネ一覧グリッド

【カット割り・演出】
- 基本は固定2ショット。強い主張・数字でズームイン、笑い・オチで引き。
- 章の切れ目: グリッチ／赤ワイプ帯／ブラー、章タイトルはズームで登場。
- 要所に紫グロー(ビネット)、手描き風数字、効果音(笑)。
```
