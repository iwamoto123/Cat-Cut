# テロップスタイル割り当て指示 (テンプレ)

このファイルをコピーして `runs/<run>/style_directives.md` として、動画の内容に合わせて編集する。
AI サブエージェントがこれを読み込んで `telop.txt` の各ページに `@style=<preset>` を付与する。

## 全体方針

(基本どの preset を使うか、何を強調するかを書く)

例:
- 基本は default を使う
- 重要数字・断言は highlight
- 質問・問いかけは question
- 否定・警告は warning

## 強調する内容 (highlight)

(具体例を箇条書きで書くと AI が認識しやすい)

例:
- 数字・割合・点数が出るセリフ (「7割」「100点」)
- 結論・断言 (「行ける」「間に合う」「決定」など)
- 動画タイトル・トピック切替

## 質問・問いかけ (question)

例:
- ホスト/インタビュアーの問い
- 文末が「?」「ですか」「のか」
- 視聴者への呼びかけ

## 注意・否定 (warning)

例:
- 強い否定・注意喚起
- 「やってはいけない」「焦って〜じゃなく」

## それ以外

例:
- ナレーション的補助は simple
- 迷ったら default

## 厳守ルール

- ID行 (`# cut_XXX_pYY`) と空行構造を絶対に変更しない
- 本文を変更しない (telop.txt の校正は別工程で済んでいる前提)
- ヘッダー末尾に `@style=<preset>` を半角スペース区切りで追加するだけ
- default は明示しない (省略でデフォルト適用)
- 連続するページに別 style を多用しない
- 1動画で highlight は 30〜50ページ、warning/question は各 5〜15ページ程度が目安
