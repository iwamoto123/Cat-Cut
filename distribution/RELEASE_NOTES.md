# Cat-Cut 更新内容（2026年9月9日）

バージョン: `20260909-electron-install-repair`

## 9月9日の起動不具合修正

- 新しいPCで、インストール完了後も「Electron failed to install correctly」と表示され、編集画面が開かない問題に対応しました。Node.js 26などでも正常に展開できるライブラリへ更新し、Electron本体が実際に動作することを確認してから完了と表示します。
- 書き出しに使うブラウザの取得にも同じ展開ライブラリの修正を適用しました。
- 起動時にエラーが起きた場合は、エラー内容を確認できるようターミナルを残します。
- `install.command` のアクセス権限エラー時の実行方法と、既存PCのElectron修復方法を「はじめにお読みください.md」に追記しました。

以下の9月8日版の編集機能改善も含まれています。

## 更新方法

1. Cat-Cutで「保存済み」を確認し、アプリを終了してください。
2. Nextcloudの `CatCut-haifu/README.txt` に記載された最新の `CatCut-haifu-YYYYMMDD.zip` をダウンロードして展開します。
3. **いま展開したフォルダ**の `install.command` を右クリックして「開く」を選びます。
4. 完了後、デスクトップの `Cat-Cut.command` から起動します。

更新後は `~/CatCut/VERSION.txt` が上記のバージョンになっていることを確認してください。既存のプロジェクト・編集データは引き継ぎます。以前ダウンロードした展開フォルダを再使用すると旧版へ戻るため、今回ダウンロードしたものを使ってください。

## テロップ

- 色の付いた文字を修正したときや改行したときに、強調色が消える問題を修正しました。日本語変換中・保存後・書き出しでも色を保持します。
- プレビュー下の「テロップ位置」から、上下左右のドラッグ・横/縦の数値入力・中央/下/自動配置を使えます。「この位置を全シーンに適用」でまとめて変更でき、⌘Zで戻せます。
- 位置を調整している間、重なった画像を誤って動かさないようにしました。文字が画面に収まる範囲で移動できます。
- 倍速にした動画の後半テロップが欠ける場合がある問題を修正しました。

## カット・再生・結合

- シーン検品の波形では、Bでカットモードに切り替え、ドラッグまたは2点クリックで範囲を削除できます。先頭/末尾の発話外の部分は1クリックで削除できます。時刻と削除尺を確認し、Escで取り消せます。Aで選択モードへ戻ります。
- タイムラインでは、Bに切り替えて映像クリップをクリックすると表示時刻で分割します。
- 指定範囲の外側に短い部分が残っていても、巻き込んで削除しないようにしました。
- 「次と結合」または⌘Mで、カット前後の残ったブロックを結合できます。結合や本文修正でカット済みの映像・無音が復活しないようにしました。
- 再生中のSpaceは映像・BGM・効果音を停止します。ボタンや再生スライダーをクリックした後もB/A/Spaceを使えます。文字入力中は通常の入力を優先するため、Escで入力を終えてから操作してください。
- 選択した画像・BGM・テロップ・映像のDelete/⌘Zを統一しました。Undoは直近200操作までです。

## 画面・読み込み・書き出し

- BGMの波形、音量・フェードの調整、選択対象の数値欄を整理しました。縦型でもプレビューの下に再生バー・速度・音量を表示します。
- 動画末尾へ移動して編集しやすくし、小さい画面での文字の不自然な折り返し・設定欄の見切れを修正しました。
- 波形・動画配信・保存・書き出しのキャッシュ処理を改善し、重複処理とメモリ使用を抑える変更を含みます。
- OPをONにしても候補不足で無地の導入になる場合を改善しました。

## 編集からの学習

- 書き出しが成功した編集から、文章校正・カット・シーン区切り・改行の変更前/変更後を記録し、次回のAI校正で関連する事例を参照します。
- 「編集からの学習」で記録内容を確認し、不要な事例を除外できます。既に編集済みの旧プロジェクトは、記録開始時の状態から変更を蓄積します。
- 書き出し後の「編集学習データを共有」では、学習用JSONと確認用TXTを共有フォルダへ保存します。TXTだけに最終本文を残す方式から、比較できる記録へ改善しました。
- 記録が増える仕組みを実装していますが、AIの精度向上率を実測したものではありません。
