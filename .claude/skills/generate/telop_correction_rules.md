# テロップ校正ルール (蓄積式)

Step 8.5b の自動校正エージェントが必ず参照するルール集。
ユーザーが手動修正した内容をパターンとして抽出し、随時この文書に追記する。

## ルール優先度

1. **ユーザー指定ルール (固有名詞・修正辞書)** ← このファイルが正
2. 一般ルール (漢数字・改行最適化)
3. 動画ジャンル別ガイド (下記参照)

ユーザーがチャットで「これを直して」「次からは○○にして」と指示した内容は **必ず** このファイルに反映する。

---

## 一般ルール

### 漢数字 → 算用数字

得点・順位・割合・人数など定量値の漢数字は算用数字に統一する。

| 変換例 | 補足 |
|--------|------|
| 七割 → 7割 | パーセンテージ・割合 |
| 三十八点 → 38点 | 得点 |
| 四十人 → 40人 | 人数 |
| 五百点台 → 500点台 | 点数帯 |
| 一年分 → 1年分 | 期間 |
| 一ヶ月後 → 1ヶ月後 | 期間 |

慣用句・固有名詞内の漢数字は維持する: 「一番」「二度と」「三日坊主」「四捨五入」「九大」「東大」など。

### 科目・教科表記

| 元 | 修正後 |
|----|--------|
| 数一A / 数1A | 数IA |
| 数二B / 数2B | 数IIB |
| 数二BC / 数2BC | 数IIBC |
| 数三 / 数3 | 数III |
| 情報1 | 情報I |

### 改行位置の最適化

- 1ページ内で文が不自然に切れている箇所は句読点・助詞境界で再分割
- 1行16文字以内を推奨(横型1920x1080, 72px の場合)
- ページ末・冒頭の意味のない単語(「で」「ま」「あの」)は前後ページに統合または削除

### 単独・無意味ページの扱い

「で」「ま」「あの」など単独で意味をなさないページは、本文を空(行ゼロ)にしてOK(=テロップ非表示)。ヘッダ行は残す。
ヘッダごと削除すると該当ページがcomposition.jsonから完全に消える(時間帯はテロップなしで再生)。

### 重複発話の統合 (Echo dedup)

2人の話者が**同じセリフを連続して発言している箇所**(リアクション・復唱・確認)は、テロップを **1行に統合** する。同じ文字列が縦に並ぶと冗長で読みづらい。

判定基準:
- 同一ページ内で同じ行が2回以上連続: 1回に圧縮
- 連続するページのテキストが完全一致 or ほぼ一致(語尾の助詞・促音を除いて同じ): 後続ページの本文を空にしてテロップ非表示にする(時間帯は残す)

例:
- 「500点台が / 500点台が」 → 「500点台が」(1行)
- 「いけると思います。 / いけると思います」(連続ページ) → 後者を空に
- 「間に合うね / 間に合います」 → これは別話者の言い方違いなので残してOK(完全一致でないため)

判定方法:
- 大文字小文字・全角半角・句読点のみの差異は同一とみなして統合
- 意味のある言い換え(別の話者の補足)は残す

## 動画ジャンル別ガイド

### 汎用トーク動画

**頻出固有名詞 (正式表記)**:
- 動画ごとに、人物名・会社名・商品名・サービス名を確認する
- アルファベット表記が正式なものは英字表記を優先する
- チャンネル名、番組名、企画名は毎回ユーザー指定を優先する

**STT誤認識パターン**:
| 誤 | 正 | 文脈 |
|----|-----|------|
| キャットカット | Cat-Cut | アプリ名 |
| キャット カット | Cat-Cut | アプリ名 |
| テロップ作成 | テロップ制作 | 編集文脈 |

**話者特徴**:
- 話者の語尾や口語表現は、意味が伝わる限り維持する
- 笑い、間、言い淀みは、動画のテンポを損なう場合だけ整理する

## ルール追記の手順 (Claude 用)

ユーザーから「○○を△△に直して」「次からは○○の方針で」等の指示を受けたら:

1. 修正パターンを抽出 (1回限りの誤字 vs ジャンル横断ルールか判断)
2. ジャンル横断なら「動画ジャンル別ガイド」または「一般ルール」に追記
3. 単発・特殊ケースなら「ユーザー追記ルール」に日付付きで追記
4. 同じパターンが3回以上出たら、汎用ルールに昇格
5. ユーザーに「ルールに追記しました: ○○」と簡潔に報告
